# Deployment assets / 部署资源

Public source contains no deployment certificates or keys. Configure your own TLS certificate and private key paths on the Hub; distribute only the public CA certificate to workers when using a private CA. Keep operator files outside the plugin directory.

公开源码不包含部署证书或密钥。请在主机配置自己的 TLS 证书与私钥路径；使用私有 CA 时，仅向从机分发公开 CA 证书。部署文件应放在插件目录之外。
